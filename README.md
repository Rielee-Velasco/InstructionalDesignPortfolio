# Instructional Design Portfolio

This repository contains a static portfolio website for showcasing instructional design work.

## About

The featured project is a short e-learning course for pharmacy managers that teaches the GROW coaching model to improve team performance.

## Preview

Open `index.html` in a browser to preview the site locally.

## GitHub Pages

To publish this portfolio with GitHub Pages:

1. Commit the files to the `main` branch.
2. In the repository settings, enable GitHub Pages from the `main` branch.
3. Visit `https://Rielee-Velasco.github.io/InstructionalDesignPortfolio/` after publishing.

## Customize

Update `index.html` with additional projects, your biography, and links to sample courses or storyboards.
